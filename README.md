# Temp

A lightweight sandbox repository for testing Git and GitHub workflows before applying changes to production projects.

## Purpose

- Practice commits, branches, and pull requests
- Test GitHub integrations and automation
- Experiment safely with files and repository settings
- Validate development workflows

## Getting Started

```bash
git clone https://github.com/Anmol-Malviya/temp.git
cd temp
```

## Repository Status

This repository is intended for temporary experiments and testing. Its contents may change frequently.
